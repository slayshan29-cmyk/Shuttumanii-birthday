SHUTTUMANII BIRTHDAY WEBSITE

Files:
- index.html : the birthday website
- True Love.mp3 : your supplied music file

How to use:
1. Extract the ZIP.
2. Keep index.html and True Love.mp3 in the same folder.
3. Open index.html in a browser, or upload both files to your website hosting.

Music note:
The website attempts to start the song automatically when opened. Many mobile browsers block autoplay with sound, so tap the music button or tap the page once if it does not start. The song is the file you supplied; only use/share it where you have the necessary rights.
